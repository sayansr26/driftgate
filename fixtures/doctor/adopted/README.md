# `doctor/adopted`

A repository with **all five adapters enabled and synced**. Its point is that
`CLAUDE.md`, `AGENTS.md` and `GEMINI.md` come out byte-identical and
`.github/copilot-instructions.md` is a fourth near-copy — correct output from four correct
adapters, which is exactly why T078 belongs to inspection rather than to generation.

Five adapters is the minimum that reproduces it. With two, the outputs have different
shapes and never overlap.

The generated files here are real `driftgate sync` output and are regenerated by
`pnpm fixtures:update`, so they cannot drift from the adapters.

The three faults T026's validation names — an orphan, an oversized file and a symlink — are
**not** here. `packages/cli/test/doctor.test.ts` creates them in a temp copy, because git
checks a symlink out as a plain text file on Windows without `core.symlinks=true`, and a
committed one would leave the symlink guard green while testing nothing.
